## Certificate and consumer

Authenticated loopback POST /maintenance/verify rechecks the issuing process,
the exact issued certificate, current admission/counters/coverage and a fresh
bounded database observation. It does not mint a replacement certificate.
Changing certificate fields, including expiry, is rejected. TTL is 10,000ms.

Test-DrainConsumer.ps1 inspects full container/image IDs and StartedAt before
and after verification, restricts the project/network, binds deployment identity
to the inspected hostname, checks expiry, then asks the existing Backend process
to verify boot ID, drain operation and activity revision. The exec Node process
is only an HTTP client; it does not infer another process's RAM state.
