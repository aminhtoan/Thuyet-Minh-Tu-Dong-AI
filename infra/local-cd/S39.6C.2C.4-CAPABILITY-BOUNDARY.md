## Boundaries strengthened

### TranslationAttempt default repository

services/translation/customer-attempt.ts wraps its default repository with
trackedObject(..., 'activeOperations'). Every method registers before its body
executes, including raw collection insertOne/updateOne, model updates and the
quota transaction. The original promises, original sessions, withTransaction
callback/options, sequential DB operations, and finally endSession are unchanged.
The outer lease remains until the repository promise settles including its
existing cleanup. No new transaction, callback replay, fee or CLAIMED/UNCERTAIN
retry is introduced. Nested counters are reference counts, not locks, and do not
wait for each other. Tests can inject a runtime into trackedObject without
altering the production singleton.

This is a scoped repository boundary, NOT global Mongoose interception. Writes
through other imported models/collections remain UNKNOWN. Tests use fake writes
and deferred transaction callbacks; no actual Mongoose server was used.

### Default GROUPS_V1 expiry scheduling

New maintenance/scheduled.ts scheduleCapability registers before invoking a
scheduler. Its lease covers pending time, callback execution and a returned
Promise's settlement. Cancellation first cancels the scheduler, then releases
only a still-pending callback; cancelling while running does not release work.
An already-cancelled queued callback cannot execute its body. Synchronous
scheduler errors release the lease; callback failures invalidate entry-point
coverage and release tracking. Async callback rejection is recorded as unknown
coverage rather than an unhandled rejection or false-safe result.

group-draft-store.ts default scheduleExpiry now uses this wrapper, retaining the
same unref timer, TTL, natural expiry and clearTimeout behavior. Pending expiry
continues blocking drain even if the logical draft TTL has elapsed until the
actual callback/cancellation settles. No draft or approval is purged to obtain
quiescence. A live draft is retained normally. This intentionally strengthens
maintenance observations; a deploy may remain blocked until the existing timer
expires. It does not change translation text, approval or retry policy.

Custom injected schedulers are not silently certified. Direct restore/prune/get
mutations outside tracked HTTP are not a completed capability boundary.

## Boundaries not closed

| Boundary | Concrete evidence / remaining risk |
| --- | --- |
| Global Mongoose | services/admin.service.ts narration.save; auth.service.ts User.create/AuthSession.create; raw model/collection imports elsewhere can bypass the scoped repository |
| Other transactions | source-language.service.ts, transcription.service.ts, result.service.ts, customer-soft-delete.service.ts, group-translation.service.ts create sessions directly; enclosing HTTP tracking is insufficient for direct imports |
| GROUPS RAM mutations | group-draft-store.ts restore/prune/get and injected schedulers require explicit capability at every public mutation entry, not just default timer registration |
| SDK late work | GoogleGenAI interactions/create and provider SDK-owned callbacks are not proven to end with the outward promise. Translation bounded-fetch tracks cancellation cleanup but not every possible SDK/transport continuation |
| Streams | Prior trackedReadStream/createTrackedResource retain descriptors until close. This is local coverage, not proof of every raw stream or SDK reader/finalizer |
| Startup | server.ts startup registration and tracked mongoose init exist, but connect/index/driver reconnect/internal callbacks are not proven closed-world |
| Graceful shutdown | signal hooks/disconnect mark shutdown unknown. Do not suppress shutdown to claim fencing |
| CLI/scripts | Backend Docker CMD is node --import staging/preflight.mjs dist/server.js; scripts are not automatically started. Separate seed/maintenance/controlled-development processes are nevertheless not covered by this process coordinator; external invocation and DB writer ownership need constraints |
| Test entry points | Synthetic runtime and injected repositories/schedulers are explicit fixtures, never an authorization to certify normal production |

No global monkeypatch/plugin was added to pretend all writes are covered:
Mongoose middleware alone would miss raw collection/driver work and other
processes. Session and transaction semantics were not changed to simplify tests.

## Conclusion

PARTIAL for scoped boundary implementation; **BLOCKED for production fencing**.

mutations and a provable SDK finalization/ownership contract, plus supported

synthetic tests cannot substitute for those proofs. Replacement stays disabled.
